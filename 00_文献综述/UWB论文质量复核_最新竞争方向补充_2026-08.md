# UWB 论文质量复核补充：最新直接竞争方向

旧版短名单形成后，网络检索又核验到三类必须纳入的新证据：

1. **IEEE TIM 2025 RAS** 已用残差选择/剔除 NLOS 测量；
2. **IEEE Sensors Letters 2024** 已用链路质量和测距误差做实时 anchor selection；
3. **IEEE TWC 2026** 已用所有锚点 CIR 的 Transformer 直接输出位置修正。

因此，原先“风险—几何联合锚点选择”不能单独宣称新颖；它应降为下游消融/决策模块。当前选题的独立性应建立在“跨环境测距区间校准失效诊断、测量区间到位置风险传播、接受/降级/拒绝决策”三者的闭环上。

同时，AdaLOS（IEEE IoTJ 2025）和 Fontaine 等（IEEE IoTJ 2024）说明“跨环境域适应/迁移学习”也已形成成熟支线。仅增加 MMD、对抗域适配或一个新 backbone，难以构成 Measurement/TIM 层面的充分创新。

建议 Related Work 按如下顺序组织：

```text
信号特征与 NLOS 分类
 -> 误差补偿与鲁棒滤波
 -> 可信度/不确定性建模
 -> 跨环境迁移与域适应
 -> 残差/链路质量锚点选择
 -> 本文：区间校准失效 -> 几何传播 -> 风险控制定位
```

本补充与《高质量UWB定位论文检索与方法分析_2026-08.md》配套使用；后者包含逐篇方法拆解、评分、D1 字段适配和实验矩阵。
