# D1 数据集相关使用论文追踪

更新时间：2026-07-19

## 1. 总体判断

D1，即 Klemen Bregar 于 2023 年发布的 **Indoor UWB Positioning and Position Tracking Data Set**，已经被较多论文引用。Nature 页面当前显示约 48 次引用，OUCI 页面显示约 37 次引用；不同数据库统计口径不同。

但是需要区分两类文献：

1. **引用型文献**：只是把 D1 作为公开 UWB 数据集、相关工作或数据资源引用；
2. **实验型文献**：真正使用 D1 的 range/CIR/anchor/tag 数据做算法验证。

对我们更重要的是第二类。当前可明确确认的实验型使用论文数量不算很多，这意味着该数据集仍有继续深挖空间。

## 2. D1 原始数据集论文

**Indoor UWB Positioning and Position Tracking Data Set**  
Klemen Bregar, Scientific Data, 2023  
DOI: `10.1038/s41597-023-02639-5`

数据特点：

- 4 个室内环境；
- 8 个 anchors，1 个 mobile tag；
- DW1000/DWM1000 UWB；
- ADS-TWR range；
- 每个 tag position 采集多个 range 和 CIR；
- 每个位置有 48 个 anchor-channel 文件；
- 支持 WLS、range error、RSS、CIR、LOS/NLOS 分析。

这是我们第一篇 SCI 的主数据集。

## 3. 明确使用 D1 的相关论文

### 3.1 Neurodynamic robust adaptive UWB localization algorithm with NLOS mitigation

期刊：Scientific Reports  
年份：2025  
DOI: `10.1038/s41598-025-99150-1`

该文明确在 real world experiments 中使用 Bregar 的 UWB localization dataset。其目标是面向 LOS/NLOS 混合环境提出 robust adaptive localization algorithm，即 AR-PNN。

使用方式：

- 主要使用 UWB range 与 anchor 坐标；
- 分析真实环境中的 ranging error；
- 比较不同 robust localization algorithms 的轨迹误差、CDF 和 RMSE；
- 关注 NLOS mitigation 与 robust optimization。

对我们研究的启发：

- 说明 D1 已经被用于鲁棒定位论文验证；
- 但它主要从优化/robust loss 角度处理 NLOS；
- 没有充分利用 CIR 进行测距可信度和不确定性建模；
- 没有把 uncertainty calibration 作为核心贡献。

对我们应避开的重复点：

- 不要只提出另一个 robust loss 或 neurodynamic solver；
- 不要只在 environment0/apartment 上验证；
- 不要只做 RMSE/CDF，需要加 cross-environment、anchor dropout、calibration。

### 3.2 An enhanced mobile localization algorithm integrating multiple AUKF models for mixed indoor environments

期刊：Measurement Science and Technology  
年份：2024 online / 2025 issue  
DOI: `10.1088/1361-6501/ad894c`

该文提出 IMM-AUKF，用于 mixed LOS/NLOS indoor environments。论文摘要和正文说明使用 simulation、open-source dataset validation 和实际实验验证。

使用方式：

- 使用 D1 作为 open-source dataset validation；
- 构建 LOS 和 NLOS ranging models；
- 使用 AUKF 与 IMM 处理 LOS/NLOS 混合环境；
- 重点在动态滤波和过程噪声自适应。

对我们研究的启发：

- D1 已经被用于滤波类动态定位算法；
- 说明 reviewer 会接受 D1 作为 UWB 定位验证数据；
- 但该文核心仍是 filter/model switching，不是 per-link signal-informed trustworthiness。

对我们应避开的重复点：

- 不要把创新写成“新的 AUKF/UKF/IMM”；
- 不要只做 LOS/NLOS 双模型；
- 我们应强调每条测距的连续不确定性、可信度评分和几何鲁棒融合。

### 3.3 UWB Positioning in Complex Indoor Environments Based on UKF-BiLSTM Bidirectional Mutual Correction

期刊：Electronics  
年份：2026  
DOI: `10.3390/electronics15030687`

该文将实验分成 NLOS recognition 和 NLOS error mitigation 两部分。NLOS error mitigation 部分明确使用 Klemen Bregar 2023 年发布的 open-source indoor UWB positioning and tracking dataset。

使用方式：

- 使用 D1 的四个室内环境；
- 关注 NLOS error mitigation；
- 对 Environment 2 中 A6 异常进行剔除；
- 区分环境 0/1 的轻干扰与环境 2/3 的严重干扰；
- 提出 UKF-BiLSTM 双向校正框架；
- 还做了不同 anchor 数量下的 anchor-level RMSE。

对我们研究的启发：

- 这篇和我们的方向最接近，因为它已经使用 D1 做 NLOS error mitigation；
- 它也注意到了 environment 2/3 更困难、A6 异常、anchor 数量影响；
- 它使用深度学习 + UKF，但主要是动态误差校正。

对我们应避开的重复点：

- 不要只做 UKF + BiLSTM；
- 不要只强调误差补偿；
- 我们需要把创新集中在 `bias + uncertainty + trustworthiness` 三输出，以及跨环境泛化和不确定性校准。

### 3.4 Real-time delay-compensated UWB localization for dynamic agents via deep trajectory prediction

期刊：Expert Systems with Applications  
年份：2026  
DOI: `10.1016/j.eswa.2026.132248`

该文使用 open-source Indoor UWB Positioning and Tracking Dataset，关注 delay-compensated UWB localization 和 deep trajectory prediction。

使用方式：

- 使用 D1 的四个室内环境；
- 结合 CIR features 与 motion history；
- 比较 CNN-Transformer、LSTM、Transformer 和 constant velocity baseline；
- 目标是补偿系统延迟并预测短期轨迹。

注意：

- 该文页面显示的期刊排期日期为 2026-08-01，晚于当前日期 2026-07-19，但页面已可检索。引用时应以最终出版状态为准。

对我们研究的启发：

- 说明 CIR + trajectory prediction 已经有人做；
- 如果我们后续使用运动历史，要避免变成 delay compensation/trajectory prediction 论文；
- 我们的主线应保持在 measurement reliability，而不是预测未来位置。

## 4. 引用但不一定实验使用的相关文献

以下论文或综述会引用 D1，但未必直接使用其数据做算法实验：

1. **Machine Learning Integration in Ultra-Wideband-Based Indoor Positioning Systems: A Comprehensive Review**  
   Electronics, 2026  
   将 D1 列入 UWB/indoor positioning 数据集相关资源。

2. **Comparative study of indoor positioning datasets focusing on localization accuracy success rate and floor classification**  
   Scientific Reports, 2025  
   引用 D1 作为公开 indoor positioning dataset 之一，但其主要实验集中在 WiFi/BLE fingerprinting datasets。

3. **Data set for UWB Cooperative Navigation and Positioning of UAV Cluster**  
   Scientific Data, 2025  
   引用 D1 作为已有 UWB 数据集背景，用于说明新 UAV cluster dataset 的定位。

这类文献适合写 related work 的数据集背景，但不应作为直接 baseline 对照。

## 5. 与我们选题的关系

目前已使用 D1 的论文大致集中在：

- robust optimization；
- AUKF/UKF/IMM 类滤波；
- BiLSTM 误差校正；
- trajectory prediction/delay compensation；
- LOS/NLOS 或 NLOS mitigation。

仍然没有被充分覆盖的空间：

1. **连续测距可信度建模**  
   不是二分类 LOS/NLOS，而是输出 per-link trustworthiness。

2. **测距不确定性校准**  
   不只是给权重，而是评价 `sigma` 是否可信，例如 NLL、ECE、coverage、risk-coverage。

3. **CIR + geometry + temporal 的联合质量因子**  
   现有工作大多偏滤波或误差补偿，没有系统把 CIR、几何退化和时间稳定性融合成可解释质量变量。

4. **跨环境泛化协议**  
   一些论文使用四个环境，但未必严格执行 leave-one-environment-out，也未必把跨环境退化作为主贡献。

5. **锚点退化与风险感知定位**  
   anchor dropout、poor geometry、long-tail failure 与 uncertainty calibration 可以成为我们的实验特色。

## 6. 结论

D1 数据集已经被认可，也已经有若干论文使用它验证 UWB 定位算法。但现有使用方式多集中在滤波、鲁棒优化或 NLOS 误差补偿。

我们的切入点不应是“再提出一个滤波器”，而应是：

> 基于 D1 的 CIR、RSS、测距残差和几何信息，建立单链路测距偏差、可信度和不确定性的联合模型，并通过鲁棒几何定位验证其跨环境泛化能力和长尾风险抑制能力。

这仍然有明确创新空间。
