# 公开 UWB 定位数据集比较与外部验证建议

**目标：** 为 D1 的“跨数据域测距区间校准与风险可控定位”寻找外部验证数据。  
**原则：** 不按室内/室外限定，而按 TWR/TDoA、CIR/测距字段、动态性、几何变化和可复现性分类。

## 1. 最值得关注的数据集

| 数据集 | 协议/平台 | 关键字段与规模 | 最适合验证的内容 | 对当前课题的价值 |
|---|---|---|---|---|
| **IDLab UWB TWR Correction** | ADS-TWR，移动机器人，23 锚点 | Range、RSS/FP、完整 CIR、MOCAP 真值；同一工业场景相隔 6 个月的两次采集 | 跨时间测量域泛化、误差校正、区间校准 | **最适合作为 D1 后的第一外部验证** |
| **IDLab UWB TDoA Correction/Fingerprinting** | TDoA，移动机器人，工业环境 | 15/8 锚点轨迹、完整 CIR、射频诊断、MOCAP；LOS/NLOS 和不同轨迹 | 从 TWR 扩展到 TDoA、CIR 风险建模 | 适合证明方法不是只适配 D1 的 TWR |
| **UTIL** | TDoA，Crazyflie 飞行平台 | LOS/NLOS 识别数据、SNR、功率差、四种锚点构型、IMU/光流/ToF、约 150 min 飞行 | 动态障碍、几何变化、TDoA 测量风险 | 适合作为第二阶段动态验证 |

| **NTU VIRAL** | UAV 多模态：UWB+视觉+LiDAR+IMU | 多个室内/室外场景、UWB 测距、激光跟踪真值和完整多传感器 | UWB 辅助 VIO/SLAM、动态飞行 | 代表性强，但更偏融合定位而非单链路测量学 |

## 2. 重点数据集分析

### 2.1 IDLab UWB TWR Correction Dataset：首选外部验证

IDLab 官方页面说明，该数据集采用 ADS-TWR，在 23 锚点工业 IIoT 场景中由移动机器人采集；提供高精度 MOCAP 真值、Range、FP/RSS、完整 CIR 和射频诊断。最有价值的是两次采集相隔 6 个月，第二次包含更多货物、遮挡和轻微锚点扰动，可直接构造“时间变化的测量域”。

这与当前研究非常匹配：

```text
D1 environment 留出
        -> IDLab 6 个月后数据留出
        -> 比较区间 coverage、校准误差、P95 和 Fail@1 m
```

它还允许研究“只校准测量层，不重新训练定位网络”是否可以适应时间变化。数据集页面提供 GitLab、Hugging Face 和下载入口，数据集采用 Apache-2.0 标识。

### 2.2 IDLab UWB TDoA CIR Dataset：协议迁移验证

该数据集来自同一工业 IIoT 场景，包含 Racks、Racks 2、Tour、Random、Grid 等轨迹，提供每包 CIR、FP/PP 索引、CIR 功率/噪声、RSS、时间戳、MOCAP 真值和锚点坐标。它的优势是同时包含 LOS 和 NLOS 轨迹，以及 8/15 锚点配置。

如果在 D1 上完成 TWR 测距区间校准，可以将方法改写为 TDoA 观测区间或链路差分风险，验证其是否具有协议迁移能力。这比简单换一个室内数据集更有说服力。

### 2.3 UTIL：动态障碍和 TDoA 几何验证

UTIL 提供两部分数据：静态 LOS/NLOS 识别实验，以及约 150 分钟的 Crazyflie 飞行数据。飞行数据包含四种锚点构型、动态/静态障碍、TDoA、IMU、光流、ToF 和高精度真值，适合评价测量风险随动态遮挡和锚点几何变化的传播。

它的主要限制是协议从 D1 的 TWR 变为 TDoA，且需要处理异步时钟和飞行时序。因此建议作为第二外部验证，而不是一开始就混入 D1 训练。

### 2.4 MILUV：动态多机器人和多模态验证

MILUV 包含 217 分钟、36 次实验、3 架四旋翼、最多 12 个 UWB 收发节点，提供原始时间戳、CIR、视觉、IMU、激光高度、磁力计和 Mocap 真值，并同时包含 LOS/NLOS 条件。

它适合回答：

- 测距区间能否支持快速运动？
- UWB 风险是否可以指导 UWB/视觉融合权重？
- 多 UAV 场景下链路风险是否具有跨节点泛化性？

限制是数据规模和传感器同步处理复杂，且研究容易转向 UWB-视觉融合，偏离当前测量学主线。

### 2.5 Comprehensive Outdoor UWB Dataset：跨物理场景验证

该 Scientific Data 数据集公开提供室外静态和动态 SS-TWR 测量，包含 Range、RSS、CIR；静态距离最高约 60 m，并提供不同天线高度、LOS/NLOS 条件和 PDOP；动态部分包含四锚点机器人、GNSS/RTK、IMU 和 ROS bag。

它非常适合检验：

- 在 D1 室内数据上校准的模型，到了室外长距离是否失效；
- 区间宽度是否随距离、天线高度和 PDOP 合理变化；
- 几何风险和测量风险是否可以分离；
- 只使用 Range/RSS/CIR 的方法是否可以迁移，不依赖室内环境标签。

这是当前“外部验证”中最重要的数据集之一。

### 2.6 Industrial AMR UWB Localization：工程部署验证

Klagenfurt 大学公开的工业 AMR 数据集包含 13 条轨迹、3 个车载 UWB 标签和 12 个固定锚点，配套 LiDAR 参考位姿、轮速和车体速度；场景覆盖工业仓库、相邻室外区域、室内—室外过渡、部分遮挡和稀疏锚点。

它没有 D1 那样丰富的 CIR 字段，但非常适合验证位置层结论：

- 风险预算能否控制车辆定位失败；
- 稀疏锚点下位置保护区域是否仍有效；
- UWB 风险是否能够自适应地调节 UWB—里程计融合。

其数据集为 CC BY-NC-SA 4.0，允许非商业研究使用，但不能用于商业产品。

### 2.7 TWR-CLOUD-Bern：大规模协作定位

TWR-CLOUD-Bern 是 2026 年公开的新数据集，使用 40 个 Qorvo DWM3001C 节点、12 次扫描、超过 500 m² 空间，提供节点间 ToF/Range、接收统计和协议阶段统计，并设置独立留出扫描和官方 scorer。数据量约 29.8 GB，许可证为 MIT。

它适合研究：

- 锚点辅助协作定位和无锚点协作定位；
- 网络规模扩大后测量不确定性如何累积；
- 协作链路的风险传播。

但它没有 D1/IDLab 那样明确的 CIR 主线，数据量也很大，不建议作为当前第一外部验证。

## 3. 与当前研究的匹配度

| 研究问题 | 首选数据集 | 次选数据集 |
|---|---|---|
| 跨测量域区间校准 | D1 + IDLab TWR Correction | Outdoor UWB |
| 跨时间泛化 | IDLab TWR Correction | D1 四环境 |
| 跨协议泛化 | D1 TWR + IDLab TDoA CIR | UTIL |
| 跨物理场景泛化 | D1 + Outdoor UWB | Industrial AMR |
| 锚点/链路缺失风险 | D1 + Industrial AMR | TWR-CLOUD-Bern |
| 动态运动与遮挡 | UTIL / MILUV | Industrial AMR |
| 多机器人协作 | MILUV / TWR-CLOUD-Bern | UAV Cluster |

## 4. 推荐数据使用路线

### 阶段一：只使用 D1

完成四个 environment 轮流留出，验证方法是否真的能识别数据域变化，并建立完整指标体系。

### 阶段二：加入 IDLab TWR Correction

这是最自然的外部验证：仍是 TWR、仍有 CIR 和测距诊断，但引入工业场景与六个月时间变化。可形成：

> **within-dataset domain shift + temporal domain shift**

### 阶段三：加入 Outdoor UWB 或 Industrial AMR

- 想证明跨物理场景泛化：选择 Outdoor UWB；
- 想证明工程车辆部署价值：选择 Industrial AMR。

不要一开始同时加入所有数据集，否则协议、硬件、时间戳、坐标系和评价指标会失控。

## 5. 当前最推荐的组合

**D1 + IDLab TWR Correction + Outdoor UWB Dataset**

这个组合分别提供：

- D1：四个测量域、完整 CIR、TWR、多锚点静态轨迹；
- IDLab：工业环境、完整 CIR、六个月时间变化、MOCAP；
- Outdoor UWB：长距离、不同天线高度、PDOP、动态机器人和室外 LOS/NLOS。

它能够支持一篇真正有外部泛化证据的论文，而不是只在单一数据集上调参。
