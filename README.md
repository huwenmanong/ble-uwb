# UWB public-dataset research

本仓库原始主题为 `ble-uwb`：基于BLE和UWB的分级定位方案研究。本研究分支保存独立开展的 SCI-UWB 公开数据集研究，保留原仓库提交历史。

面向跨环境 UWB 测距可靠性与稳健定位的研究代码和实验记录。

## 当前状态

这是进行中的研究，不是已验证论文方法。历史结果包含后续发现的数据协议问题，请先阅读最新阶段报告；不要直接引用旧指标作为方法优势。

## 目录

- `00_文献综述`：文献研究记录，不提供论文全文。
- `01_研究方案`：研究计划。
- `02_公开数据集`：数据说明。
- `03_实验协议`：划分与实验记录。
- `04_算法实现/scripts`：Python代码。

## 数据与运行

D1 数据集论文 DOI：10.1038/s41597-023-02639-5。数据应从作者授权来源另行获取，并遵守原始许可证及引用要求。仓库不分发数据集、论文 PDF、模型和大型中间文件。

开发环境为 Python 3.9 的 bluekey 环境。运行说明见 `04_算法实现/脚本运行说明_bluekey.md`。部分历史脚本依赖本地目录布局及先前生成的中间文件，目前尚非下载后即可完整运行的独立软件包。

已知协议问题包括：E2-A6硬件故障、原始与官方处理测距的校准边界、坐标修正及非正测距处理。真值仅用于训练标签及评价，不应作为部署输入。

## 版本管理

默认仅纳入研究文档和代码；原始数据及全部本地结果保留在本机。文档中的本地链接可能需要自行生成对应结果后才能使用。

尚未指定本项目代码的开源许可证；第三方数据和算法不因上传本仓库而改变其原有授权。
