更新时间：2026-07-19

## 1. 数据集与粒度判断

本次审计对象为 `SCI-UWB/数据集论文/data_set`。该数据集已经解压，包含四个室内环境、整理后的 `data.json`、原始逐点逐锚逐信道 CSV、anchor 坐标、walking path 坐标和技术验证图。

适合本研究的核心粒度建议设为：

```text
environment_id + tag_position + channel + anchor_id + measurement_index
```

也就是说，每一行原始 CSV 记录是一条单链路 UWB 测距观测，可用于构造 `range_measured`、`range_true`、`ranging_error`、信号特征和 NLOS/LOS 标签。

## 3. 字段可用性

README 给出的原始 CSV 字段包含：

```text
TAG_ID, ANCHOR_ID, X_TAG, Y_TAG, Z_TAG, X_ANCHOR, Y_ANCHOR, Z_ANCHOR, NLOS, RANGE, FP_INDEX, RSS, RSS_FP, FP_POINT1, FP_POINT2, FP_POINT3, STDEV_NOISE, CIR_POWER, MAX_NOISE, RXPACC, CHANNEL_NUMBER, FRAME_LENGTH, PREAMBLE_LENGTH, BITRATE, PRFR, PREAMBLE_CODE, CIR...
```

这些字段对拟定研究非常有价值：

- `RANGE` 可作为原始测距；
- `X_TAG/Y_TAG/Z_TAG` 与 `X_ANCHOR/Y_ANCHOR/Z_ANCHOR` 可计算真实距离和测距误差；
- `NLOS` 可作为 LOS/NLOS 标签或困难样本标签；
- `RSS/RSS_FP/CIR_POWER/RXPACC/STDEV_NOISE/MAX_NOISE` 可作为轻量信号质量特征；
- `CIR...` 可提取峰值、能量、首径附近能量、多径扩散等深层信号特征。

## 5. 关键质量发现

### Finding 1: 数据集结构完整，可支撑主研究

四个 environment 均包含 anchor 坐标、walking path、整理后 JSON 和 raw csv。raw csv 覆盖率按 `walking_points * 48` 计算均达到审计表中的水平，字段直接覆盖 range、NLOS、RSS、DW1000 质量寄存器和 CIR。

影响：可以按照前期方案开展单链路测距误差补偿、可信度建模和跨环境定位实验。

严重性：Low。

### Finding 2: 存在 `data.json~` 备份文件

`environment3` 下检测到 `data.json~`，大小与 `data.json` 相同。它可能是解压或编辑过程中形成的备份文件。

影响：不影响 raw csv 研究路线，但后续若全量扫描 JSON 文件，需要显式排除 `*.json~`，避免重复读入 environment3。

严重性：Medium。

### Finding 3: 巨型 JSON 不适合作为第一版 loader 的主入口

每个 `data.json` 大约 1.5GB 到 1.7GB。直接全量加载会占用大量内存，也不利于调试。

影响：建议第一版工程从 raw csv 流式读取和抽样缓存开始，后续再做 parquet/feather 等中间格式。

严重性：Medium。

### Finding 4: CIR 是高价值但高成本字段

样本文件显示每行包含大量复数 CIR taps。它能支撑信号特征创新，但直接保存完整 CIR 会显著增加训练数据体积。

影响：建议第一阶段先提取轻量统计特征，例如 CIR 最大幅值、总能量、峰值位置、首径附近能量比、峰度/扩散度；完整 CIR 深度网络作为第二阶段。

严重性：Medium。
