# D1 样本特征抽取与初步误差剖析

更新时间：2026-07-19

## 1. 本次处理结果

已基于 D1 原始 CSV 建立第一版样本特征抽取流程。

脚本位置：

```text
SCI-UWB/04_算法实现/scripts/extract_d1_sample_features.py
```

输出文件：

```text
SCI-UWB/data/interim/d1_sample_features.csv
```

默认抽样策略：

```text
4 environments * 3 positions per environment * 48 files per position * 10 rows per file = 5760 rows
```

样本表共 42 个字段，已经包含：

- 原始测距：`range_measured`
- 几何真实距离：`range_true`
- 测距误差标签：`ranging_error`
- LOS/NLOS 标签：`nlos_label`
- RSS/FP/RXPACC 等轻量信号字段
- CIR 统计特征：`cir_peak`, `cir_peak_index`, `cir_energy`, `cir_mean_magnitude`, `cir_spread`, `cir_top5_energy_ratio`, `cir_fp_window_energy_ratio`

## 2. 关键字段验证

样本行能够直接构造测距误差：

```text
ranging_error = range_measured - ||tag_position - anchor_position||
```

这说明 D1 可以支撑监督式的单链路测距误差补偿模型。

样本中 CIR 长度稳定为 1016 taps，说明后续可以设计两条特征路线：

1. 轻量统计特征：峰值、能量、扩散度、首径窗口能量比；
2. 完整 CIR 深度特征：CNN/Transformer/attention，但建议作为第二阶段。

## 4. 初步研究判断

### 4.1 LOS/NLOS 二分类不够

样本中出现了一个重要现象：

- environment2 与 environment3 中，NLOS 明显带来更大测距误差；
- 但 environment0 和 environment1 的样本中，部分 LOS 组误差反而高于 NLOS 组。

这说明单纯使用 LOS/NLOS 二分类不足以描述测距可靠性。对于 SCI 论文，这是一个很好的切入点：

> UWB measurement reliability should be modeled as a continuous uncertainty/trustworthiness variable rather than a binary LOS/NLOS label.

也就是说，我们不只是“识别 NLOS”，而是判断每条测距到底有多可信、应该补偿多少、应该给多大权重。

### 4.2 测距误差存在明显环境差异

不同 environment 的误差水平差异明显。例如：

- environment2, NLOS 的 P90 绝对误差达到 1.970 m；
- environment3, NLOS 的 P90 绝对误差达到 1.428 m；
- environment1, LOS 的 P90 绝对误差也接近 1 m。

这说明跨环境泛化实验不是形式主义，而是必要实验。只在随机划分下训练测试，很可能高估模型能力。

### 4.3 CIR 特征值得优先保留

样本中每条测距都带有稳定长度的 CIR。后续第一阶段建议先使用轻量 CIR 统计特征，而不是直接训练完整 CIR 深度模型。

理由：

- 轻量特征更容易解释；
- 更适合先跑通 LS/WLS/robust WLS baseline；
- 更便于跨数据集迁移，因为外部数据集未必都有完整 CIR；
- 计算成本低，适合快速实验迭代。

## 5. 对论文创新点的直接支撑

当前样本结果直接支撑三个创新点：

1. **可信度建模创新**  
   LOS/NLOS 标签不能完全解释误差，需要连续可信度和不确定性。

2. **测距误差补偿创新**  
   `range_measured` 与 `range_true` 可直接形成 supervised ranging error label。

3. **实验设计创新**  
   四个环境误差分布不同，必须做 leave-one-environment-out 和困难样本分组。

## 6. 下一步工程任务

下一步建议进入 baseline 复现：

1. 使用 D1 raw csv 聚合每个 `environment + position + channel` 下的 8 个 anchor 测距；
2. 使用 anchor 坐标和原始 `RANGE` 实现 raw LS 定位；
3. 使用 RSS/RXPACC 或 range variance 实现简单 WLS；
4. 输出每个环境、每个 channel 的定位误差；
5. 与数据集 technical_validation 中的 WLS 图进行趋势对照。

完成这一步后，我们就能获得第一条 baseline 曲线，再往上叠加测距误差补偿和可信度权重。
