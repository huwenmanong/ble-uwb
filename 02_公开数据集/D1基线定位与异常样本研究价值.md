## 2. Baseline 方法

当前使用 2D 定位，tag 高度固定为数据中的 `Z_TAG`。

每个 `environment + position + channel + anchor` 的原始测距先聚合为：

```text
range_mean
range_std
rss_mean
rss_fp_mean
nlos_ratio
```

然后每个 `environment + position + channel` 使用 8 个 anchor 做定位。

方法包括：

- `LS`
- `WLS_range_std`
- `Robust_LS_Huber`
- `Robust_WLS_Huber`

## 3. 环境级结论

| 环境 | 最值得关注的问题 |
|---|---|
| environment0 | 整体较稳定，但 ch4/ch7 明显更差 |
| environment1 | 最容易场景，原始 LS 已较好 |
| environment2 | 主困难场景，P90 和 Fail@1.0m 高 |
| environment3 | 大多数样本中等，但存在极端位置级失败 |

最重要的是 environment2 和 environment3：

- environment2 体现普遍长尾误差；
- environment3 体现局部灾难性异常。

这两类问题正好对应论文中的两个核心实验：

```text
general long-tail robustness
localized severe failure suppression
```

## 4. Environment2：鲁棒后端确实有效，但还不够

Environment2 的 LS：

```text
Mean = 0.734 m
P90 = 1.476 m
Fail@1.0m = 22.8%
```

Robust WLS Huber：

```text
Mean = 0.573 m
P90 = 0.972 m
Fail@1.0m = 9.3%
```

这说明鲁棒核对 environment2 有明显帮助。

但它也说明一个边界：

> 鲁棒核只能在定位残差层面被动处理异常，不能在测距进入定位前判断哪条测距不可信。

所以我们的方法不能只是 robust WLS，而要在 robust WLS 之前加入 measurement reliability model。

## 5. Environment3：稳定异常值是关键痛点

Environment3 的最大误差来自：

```text
position_id = 9.87_8.32_1.20
```

该位置多个 anchor 的测距偏差达到 5 m 到 9 m 级别，但部分 `range_std` 很小。

这说明：

> 稳定测距不等于可信测距。

这是我们论文非常强的论据。传统 WLS 很容易把“低方差但高偏差”的测距赋予高权重，从而导致严重定位失败。

后续模型必须识别这种观测：

```text
low variance
high systematic bias
possibly abnormal CIR/RSS/geometry pattern
```

## 6. Anchor-level 风险

最严重的 anchor-level 长尾组合包括：

| 组合 | Mean abs ranging error | P90 abs ranging error | Mean NLOS ratio |
|---|---:|---:|---:|
| environment2, A6 | 1.474 | 8.461 | 0.417 |
| environment2, A8 | 0.897 | 2.042 | 0.881 |
| environment2, A7 | 0.868 | 1.818 | 0.929 |
| environment2, A5 | 0.829 | 1.765 | 0.869 |
| environment3, A4 | 0.758 | 1.428 | 0.691 |

`environment2, A6` 是特别有价值的案例，因为它不是 NLOS ratio 最高，却有最严重的 P90 测距误差。

这支持我们的核心观点：

> 二值 LOS/NLOS 标签不能充分表示测距可信度。

## 7. Channel-level 风险

不同 channel 的定位误差也有明显差异。例如 LS mean error：

| 环境 | 最优 channel | 最差 channel |
|---|---:|---:|
| environment0 | ch2: 0.247 m | ch7: 0.509 m |
| environment1 | ch1: 0.145 m | ch7: 0.415 m |
| environment2 | ch4: 0.516 m | ch3: 0.963 m |
| environment3 | ch5: 0.459 m | ch3: 0.571 m |

这说明 channel 信息应该进入特征系统。

后续模型至少应保留：

```text
channel_number
preamble_code
rss
rss_fp
rxpacc
cir_power
cir statistical features
```

## 8. 对论文构思的价值

当前 baseline 已经能支撑论文 Introduction 中的问题陈述：

1. UWB 测距存在环境相关长尾误差；
2. 同一环境中不同 anchor 和 channel 风险不同；
3. NLOS 标签不足以解释所有严重误差；
4. range std 无法识别稳定但错误的系统偏差；
5. 鲁棒核有效但不够，需要在 measurement level 建模可信度。

这可以自然引出我们的创新：

> 与其在定位后端被动承受异常测距，不如在每条测距进入几何定位前估计它的偏差、不确定性和可信度。

## 9. 下一步必须做的实验

下一步最有价值的是 oracle correction：

```text
range_corrected = range_mean - ranging_error
```

也就是用真实误差构造理论上限，回答：

> 如果测距误差补偿做得足够好，定位误差最多能下降多少？

如果 oracle correction 对 environment2 和 environment3 的长尾有显著改善，就说明“测距误差补偿”路线是值得投入的。

随后再做 learned correction：

```text
features -> predicted ranging_error
```

并比较：

```text
raw LS/WLS
oracle correction
learned correction
learned correction + trustworthiness weighting
```
